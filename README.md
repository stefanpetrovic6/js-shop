# 📱 JS Shop — JavaScript & jQuery E-Commerce Frontend

A multi-page e-commerce frontend built from scratch with HTML, CSS, JavaScript and jQuery.

## 📄 Features

- **Dynamic Header** — Rendered dynamically on all pages
- **Recommended Products** — Fetched via AJAX from a JSON file, 
  filtered by "recommended" flag
- **Product Catalog** — Dynamically rendered from JSON
- **Filtering & Sorting** — Paired filtering by brand, screen type 
  and color with simultaneous sorting
- **Shopping Cart** — Add to cart via Local Storage, item count 
  updates dynamically on each click
- **Cart Page** — View all added products with name, quantity and 
  total price — remove items individually
- **Form Validation** — Client-side validation with inline error 
  messages per field
- **Error Handling** — Graceful error handling across the application
- **Code Reuse** — Shared functions used across multiple pages

## 🛠️ Tech Stack

- **HTML/CSS** — Structure and styling
- **JavaScript** — Core logic and DOM manipulation
- **jQuery** — AJAX calls and DOM helpers
- **Bootstrap** — Responsive layout
- **JSON** — Local data source for products
- **Local Storage** — Cart state management

## 🚀 Getting Started

```bash
git clone https://github.com/stefanpetrovic6/js-shop
cd js-shop
```
Open `index.html` in your browser or use Live Server in VS Code.

> No build tools or dependencies required.
